# Repository assets

This directory contains first-party, redistribution-cleared, or explicitly
provisional candidate assets used by examples and tests. Record source and
license information before treating any candidate as a distributable fixture.
Runtime template inputs and upstream manuals belong in `reference/`, not here.

`sample-urban-context.png` is currently used by the direct IR example and the
AURI investigation script. Its provenance is unresolved, so packaging and
public fixture promotion must exclude it until source and redistribution status
are documented.

# md2hwp 원고 작성 지침

md2hwp v0.4.0 / IR 0.4용 Markdown 원고 작성·수정에 적용한다.
사용자가 지정한 내용·분량·문체를 따르되 아래 지원 문법 안에서 표현한다.
같은 폴더의 README-MANUSCRIPT.md는 사람용 요약이다. 규칙 변경 시 두 문서를 함께 갱신한다.

## 작업 원칙

- UTF-8 Markdown 원고와 실제 사용하는 이미지 파일을 제공한다.
- 기존 원고의 사실·수치·인용·출처와 요구된 구조를 보존한다.
  확인되지 않은 내용·이미지·출처를 만들어 넣지 않는다.
- 서식과 번호 표기는 HWP 템플릿이 정한다. 원고에 템플릿 태그를 넣거나 원본 템플릿을 변경하지 않는다.
- IR은 프로그램으로 생성한다. 이전 IR의 버전만 바꾸거나 오류를 피하려고 내용을 누락하지 않는다.
- 미지원 구조는 알리고 의미를 보존하는 일반 문단·목록·단순 표로 표현한다.

## 기본 문법

입력은 commonmark+yaml_metadata_block+footnotes+attributes+implicit_figures+pipe_tables로 읽는다.
제목:·출처:·개체 하단 설명과 인접 표 캡션 연결은 md2hwp 원고 규칙이다.

- 문단 사이에 빈 줄을 둔다. 문단 안 일반 줄바꿈은 공백으로 합쳐진다.
  강제 줄바꿈은 줄 끝 공백 두 칸 또는 역슬래시로 쓴다.
- 강조는 **굵게**·*기울임*, 제목은 #~######를 쓴다.
  장은 #, 절은 ##로 나누며 제목에 장·절 번호를 중복해서 넣지 않는다.
  실제 한글 개요 번호는 템플릿 설정을 따른다.
- 글머리표는 -, 번호 목록은 1. 등 양의 십진 시작번호를 쓴다.
  같은 항목의 후속 문단·하위 목록은 들여써서 해당 항목에 포함한다.
- 일반 링크 `[표시문](URL)`는 서식 있는 표시문으로 출력되며 클릭 가능한 링크가 되지 않는다.
- 인라인 코드·인용 블록·HTML·수식·취소선·수평선·인라인 이미지는 지원하지 않는다.
  HWPX·RST 직접 입력도 지원하지 않는다.
- 코드 블록에는 언어명·속성을, 헤딩·그림·표에는 ID 외의 속성을 붙이지 않는다.

## 문서 정보

맨 앞에 YAML을 둔다. 기본 템플릿에는 title이 필요하다.
문서 전체 제목인 title은 첫 장 제목과 별개이며 헤딩을 생성하지 않는다.

```yaml
---
title: "연구 보고서"
subtitle: "조사 결과"
author:
  - "홍길동"
  - "김연구"
date: "2026-10-08"
publisher: "발행기관"
md2hwp-report-number: "연구 2026-01"
md2hwp-heading1-start: 1
---
```

- 예시 값을 실제 정보로 바꾸고 필요하지 않은 선택 키는 생략한다.
- 지원 키는 title·subtitle·author·date·publisher와 최상위 md2hwp-<이름>이다.
  값은 비어 있지 않은 한 줄 문자열이다. author는 비어 있지 않은 문자열 목록도 허용하며
  출력에서는 순서대로 쉼표와 공백으로 연결한다. 중첩 객체·여러 문단 값은 쓰지 않는다.
- md2hwp-heading1-start만 장 시작번호 설정이다. 1~2147483647의 양의 십진 정수이며
  생략하면 1이고 # 제목마다 증가한다. 다른 md2hwp- 키는 사용자 문자열이다.
- 템플릿이 참조하는 값은 모두 제공한다. lang·keywords 등 다른 YAML 키는 지원하지 않는다.
- date는 실제 날짜를 따옴표로 감싼 문자열로 적고 전체 날짜는 YYYY-MM-DD를 권장한다.
  날짜를 모르면 현재 날짜로 대신 채우지 않는다.
  date-meta는 인식 가능한 날짜에서 파생되므로 YAML에 직접 쓰지 않는다.
  인식할 수 없거나 유효하지 않은 날짜는 date 표기만 유지한다.

## 그림

```markdown
![대상지 현황](images/site.jpg){#site}

출처: 조사기관

주.1: 조사 시점의 현황입니다.
```

- 독립 문단 전체에 이미지 하나만 둔다. 설명은 그림 캡션으로 쓰인다.
- 실제 PNG·JPG·JPEG를 사용한다. 확장자는 대소문자를 구분하지 않는다.
  JPEG는 8비트 일반 순차 또는 progressive 형식을 사용한다.
- 간편 실행에서 경로는 원고 폴더 기준이다. 이미지를 원고 폴더 안에 두고 상대 경로로 연결한다.
- 크기·비율과 캡션 배치는 템플릿과 실제 이미지 크기를 따른다.
  여러 이미지·하위 그림이나 이미지 속성으로 레이아웃을 지정하지 않는다.
- 그림 설명·캡션에 각주는 금지하고 번호 참조는 허용한다.

## 글상자

속성 없는 코드 블록을 쓴다.

````markdown
```
제목: 조사 기준

첫 번째 줄
  들여쓴 두 번째 줄

네 번째 줄
```

출처: 조사 지침
````

- 정확한 첫 줄의 제목:만 제목 후보로 처리한다. 템플릿에 slot:code.title이 있으면
  접두어와 뒤 공백 한 칸을 제거하고 바로 이어지는 빈 줄·공백만 있는 줄을 건너뛴다.
  제목 슬롯이 없으면 모든 줄을 원문대로 유지한다.
- 나머지 각 줄은 별도의 박스 문단이다. 공백·탭·본문 빈 줄을 보존한다.
- 블록 안 강조·링크·각주·번호 참조는 해석하지 않는다. 필요한 참조는 블록 밖 하단 설명에 둔다.

## 표

캡션은 위에, 하단 설명은 아래에 쓰는 구성을 우선한다.

```markdown
표: 지역별 조사 결과

{#regional-results}
| 지역 | 수량 | 비고 |
| :--- | ---: | --- |
| A | 12 | **확인 완료** |
| B | 8 | |

출처: 조사기관
```

- 머리행 하나와 구분선, 동일한 열 수의 본문 행을 가진 파이프 표를 쓴다.
  빈 셀은 허용하며 셀은 한 개의 일반 문단으로 작성한다.
- :---·:---:·---:는 왼쪽·가운데·오른쪽 정렬이다. ---는 템플릿 정렬을 따른다.
  구분선 길이로 열 너비를 지정하지 않는다.
- 셀 병합·여러 머리행·중간 머리행·꼬리행·여러 몸통·셀 안 여러 문단이나 목록·개체는 쓰지 않는다.
- 셀에는 강조·링크·강제 줄바꿈·각주·번호 참조를 허용한다. 문자 |는 \|로 이스케이프한다.
- 캡션은 별도 문단의 표:·Table:·table:·: 뒤에 공백과 내용을 쓴다.
  접두어는 출력에서 제거한다. Pandoc Markdown table_captions와 호환되는 인접 문단 규칙이며
  활성화된 CommonMark 확장이 아니다.
- 캡션은 앞뒤 한쪽에만 둔다. 두 표 사이에서 캡션 소유가 모호하면 오류다.
  아래 캡션을 사용하면 하단 설명은 그 다음에 둔다.
- ID는 표 머리행 바로 앞의 독립된 {#ID} 줄로 쓴다. 캡션 끝에 ID를 붙이지 않는다.
  번호 참조 대상 표에는 캡션이 필요하다.
- 캡션·하단 설명에는 각주를 금지하고 번호 참조는 허용한다.
- 너비는 내용과 템플릿 서식을 측정해 정한다. 너무 넓은 표는 오류가 날 수 있으므로
  의미를 보존하여 열을 줄이거나 표를 나누고 출력에서 긴 셀과 쪽 나눔을 확인한다.

## 출처와 하단 설명

그림·글상자·표 바로 뒤에 빈 줄로 구분한 별도 문단들을 연속해서 둔다.
표 아래 캡션이 있으면 그 뒤에 둔다.

- 접두어 뒤에는 즉시 콜론, 그 뒤에는 공백과 비어 있지 않은 내용을 둔다.
  출처: 내용은 허용하고 출처 : 내용은 하단 설명으로 연결하지 않는다.
- 일반 문단이나 다른 블록이 나오면 연결이 끝난다. 접두어 없는 앞 문단은 연결하지 않는다.
- 한글: 출처, 주, 주석, 참고, 자료, 설명, 비고, 단위, 기준, 해설, 약어, 참조,
  주의, 작성, 제공, 재구성, 번역.
- 영문: source, src, note, annotation, annot, reference, ref, data, description, desc,
  remark, remarks, unit, basis, commentary, cmt, abbreviation, abbr, credit, translation, trans.
  영문 대소문자는 구분하지 않으며 실제 표기·순서는 보존한다.
- 선택적 마침표를 허용한다. ASCII 숫자 접미사는 주·주석·note에만 붙이고 마침표는 숫자 앞에 둔다.
  주1:·주.1:·note.2:는 허용한다. note1.:·source1:·주..1:은 쓰지 않는다.
- ※는 접두어가 아니다. 주 번호는 자동으로 생성하거나 정렬하지 않는다.
- 강조·링크·강제 줄바꿈·번호 참조는 허용하며 각주는 금지한다.

## 각주

```markdown
본문의 설명입니다.[^detail]

[^detail]: **첫 문단**입니다. [자료](https://example.net)를 참고합니다.

    같은 각주의 두 번째 문단입니다.
```

- [^이름]과 별도 정의 [^이름]: 내용만 쓴다. ^[내용] 인라인 각주는 쓰지 않는다.
- 본문·제목·목록·표 셀, 강조 범위와 일반 링크 표시문 안에서 허용한다.
  번호 참조 링크의 표시문 안에는 넣지 말고 링크 뒤에 붙인다.
- 내용은 하나 이상의 비어 있지 않은 일반 문단이다. 후속 문단은 들여써서 같은 정의에 포함하며
  강조·링크·강제 줄바꿈·번호 참조를 허용한다.
- 중첩 각주와 각주 안 제목·목록·그림·코드·표는 금지한다.
- 그림 설명·캡션·모든 개체 하단 설명, 머리말·꼬리말·바탕쪽에 복제되는 제목에는 각주를 넣지 않는다.
- 같은 정의를 반복 참조하면 각 위치에 별도 각주가 생성된다.
  번호·구분선·위치·문단 서식은 템플릿의 네이티브 각주 설정과 샘플을 따른다.

## 번호 상호참조

```markdown
## 조사 결과 {#results}

[절 참조](#results), [그림 참조](#site), [표 참조](#regional-results)를 참고합니다.
```

- 헤딩·그림은 {#ID}, 표는 위의 독립된 ID 줄을 쓴다. ID는 문서 전체에서 유일하며
  공백·제어문자·#를 포함하지 않는다. 한글 ID를 허용하고 fig:·sec: 접두사는 필수가 아니다.
- `[표시문](#ID)`로 참조한다. 참조형 링크 정의와 빈 표시문 `[](#ID)`도 허용한다.
  표시문은 템플릿의 대상 종류별 번호 표기로 대체된다.
- 헤딩 참조는 원고 제목 순서에서 계산한 고정 텍스트다. 실제 한글 개요 번호는 필요하지 않으며
  HWP에서 제목을 이동해도 자동 갱신되지 않는다. 제목 순서는 원고를 수정하고 다시 변환한다.
- 그림·표 번호는 한글의 실제 번호 필드다. 장 번호는 참조 대상 개체가 속한 장을 사용한다.
  참조 대상 표에는 번호가 있는 네이티브 캡션이 필요하다.
- 본문·제목·목록·표 셀·각주·그림 설명·캡션·개체 하단 설명에서 허용한다.
  코드 블록에서는 해석하지 않는다. 페이지 참조와 [@...] 인용은 지원하지 않는다.
- 번호를 직접 적거나 citations·citeproc·pandoc-crossref를 추가하지 않는다.
  주변 서식과 강조를 유지하며 생성된 참조에는 하이퍼링크가 없다.
- 한글 조사를 붙여 강조할 때는 `**[절 참조](#results)는**`처럼 조사까지 함께 감싼다.
  `**[절 참조](#results)**는` 형태는 의도한 강조로 해석되지 않을 수 있다.

## 제출 전 확인

1. 실제 YAML 값·제목 계층·문단 경계·이미지 파일과 경로를 확인한다.
2. ID의 유일성, 모든 내부 참조·각주 정의, 표 열 수·캡션 소유·출처 위치를 확인한다.
3. 실행 환경이 준비되어 있으면 md2hwp.exe md2ir 원고.md --force로 문법과 IR을 검증한다.
   원고 옆 원고.ir.json을 갱신하며 한글 렌더링은 수행하지 않는다.
4. HWP 생성이 요청되면 md2hwp.exe 원고.md를 쓴다. 기본 출력은 원고.ir.json과 원고.output.hwp다.
   명시한 --output·--template 경로는 실행한 작업 폴더 기준이다.
   기존 한글 문서는 사용자가 닫아야 하며 사용자 프로세스를 강제 종료하지 않는다.
   보안 모듈 설치·등록이나 원본 템플릿을 임의로 변경하지 않는다.
5. 저장·재열기 검증과 시각적 검증을 구분한다. 실제 렌더링을 했다면 제목·박스의 잘림·겹침,
   표의 긴 셀·머리행·쪽 나눔, 각주 표시 번호를 확인한다.
   수행한 검증만 보고하고 한글 실행이나 시각 검증을 하지 않았다면 그 사실을 밝힌다.

## 제목 번호

번호를 제목이나 소속 절 목록에 표시하려면 HWP 템플릿의 제목·each.child 범위에 num:heading1~num:heading6을 지정한다. 원고에는 템플릿 태그나 표시 번호를 중복 입력하지 않는다. 번호는 원고 순서로 계산하며 ID 없는 제목도 포함한다.

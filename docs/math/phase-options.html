089 phase 표시 대안

사용자 결정에 따라 3번의 각도 기호만 사용하는 방식을 변환기에 적용했습니다. 아래는 한글 2020에서 실제 렌더링하고 추출 코드 일치를 확인한 대안입니다. 크기와 서체가 다르며 원본과 동일한 조판은 아닙니다.

원본 KaTeX

120\text{V}\phase{-78.2^\circ}\;\Large\phase{78.2^\circ}

본문 아래의 긴 선과 왼쪽 사선이 하나로 이어집니다.

1. 각도 기호 + 본문 밑줄

ANGLE {under {-78.2 ^{circ}}}

각도 기호와 본문 밑줄이 떨어집니다.

2. 각도와 본문 전체 밑줄

under {ANGLE -78.2 ^{circ}}

밑줄은 전체 폭이지만 각도 기호의 짧은 가로선이 중복됩니다.

3. 각도 기호만

ANGLE {-78.2 ^{circ}}

의미를 남기고 긴 밑줄을 생략합니다.

4. 빗금과 본문 전체 밑줄

under {"/" -78.2 ^{circ}}

원본에 가장 가까운 단순 조합이지만 빗금 기울기와 선 연결부는 다릅니다.

원본 테스트: KaTeX 테스트 자료와 MIT 고지. 한글 그림은 제시한 SCRIPT의 렌더링입니다.

# KaTeX 067 이후 미지원 사례 검토

기준: `tests/katex/cases.json`의 고정된 128개 입력. 원문을 삭제하거나
지원되는 식으로 고쳐서 성공 건수를 늘리지 않는다. 060번 이후 로고 항 제거만
기존 사용자 승인에 따른 예외다. 실제 결과는 [비교 HTML](katex.html)에 남긴다.

## 기존 규칙으로 처리한 항목

| 예제 | 처리 |
| --- | --- |
| 074–076 | mod/bmod는 native mod, pmod/pod는 인자와 괄호를 보존한다. 간격은 기존 한글 빈칸 단위로 근사한다. |
| 077 | 음수 얇은 공백 `\!`은 기존 음수 kern 정책과 같이 0으로 정규화한다. |
| 080 | `\newline`을 기존 강제 줄바꿈과 같은 행 경계로 읽는다. 분수 범위와 스타일 탐색도 행을 넘지 않는다. |
| 087 | long 화살표 별칭은 기존 방향별 화살표로 정규화한다. 고정 길이 차이는 보존하지 않는다. |
| 096 | `\mkern18mub`는 18mu 뒤의 문자 b로 읽는다. 단위 뒤 글자를 잘못된 접미사로 거부하지 않는다. 사용자 승인으로 rule만 있는 마지막 행을 제거했다. |
| 102 | 식·그룹·셀 맨 앞의 밑항 없는 첨자 `^3`은 사용자 결정에 따라 `{}^{3}`과 같은 빈 밑항 첨자 `{} ^{3}`으로 옮긴다. 역변환은 `{}^{3}`이다. 뒤의 연산자를 밑항으로 삼지 않으며 중복 첨자와 인수 없는 `^`는 계속 거부한다. |
| 105 | stackrel을 기존 overset과 같은 위쪽 주석으로 읽는다. |
| 108, 109 | 사용자 결정에 따라 cancel/bcancel/xcancel/sout을 native NOT의 한 글자 사선으로 근사한다. 여러 글자는 첫 글자에만 사선이 그어지고 역사선·X자·가로줄 구별은 사라지며 색상은 유지한다. 한글은 int·oint 등 적분 명령어 위에 사선을 그리지 않으므로(작은 점만 남음) 적분은 ∫·∬·∭·∮·∯·∰ 문자로 옮긴다. 이 문자는 일반 적분보다 작게 표시되고 첨자가 있으면 사선이 뒤의 항까지 지나간다. |
| 117 | 주석 없는 underbrace/overbrace는 빈 주석을 사용하며 뒤의 식을 소비하지 않는다. |
| 118 | maltese, degree, pounds, minuso와 텍스트의 textdollar를 해당 기호로 옮긴다. minuso의 ⦵를 다른 모양인 ominus의 ⊖로 바꾸지 않는다. |
| 120, 121 일부 | 텍스트의 명시적 공백 `\ `을 native 빈칸으로 보존한다. 121의 verb는 미지원으로 결정했다. |
| 122 | 사용자 결정에 따라 textbf·textit과 텍스트 안의 textrm·textsf·text·mbox 중첩을 지원한다. textbf는 native bold, textit은 native it이며 중첩 범위가 끝나면 이전 글꼴로 되돌린다. textsf는 기존 sans-serif 방침대로 로만이고, textrm과 함께 바깥 이탤릭을 똑바른 글꼴로 되돌린다. 한글 it은 숫자를 기울이지 않아 이탤릭 범위의 숫자는 KaTeX와 달리 똑바로 표시된다. |

080의 마지막 행 `{d+\\e}`는 TeX의 일반 수학 그룹 조판에 맞춰 한 줄로 처리한다.
단순 줄바꿈과 별표·선택 길이를 구별하며, 명시적 배열 행 구분은 유지한다.
주석 없는 중괄호와 명시적 텍스트 공백은 한글의 실제 표시와 추출 SCRIPT를 확인한다.
076의 mathbin에는 display/text에서 4mu를 기존 native 단위로 근사한
간격을 양쪽에 넣는다. script에서는 생략한다. native 자체의 서체·간격 차이는 남는다.
081의 `\not{abc}`는 `not abc`로 옮긴다. native NOT는 첫 글자에 사선을
그리며 뒤의 bc는 남는다. 임의 복합식 전체 취소선을 지원하는 의미는 아니다.
083의 rm/it/bf/tt 선언을 처리하고 sans-serif 계열은 별도 서체를 강제하지 않는다.
mathsf는 roman, mathsfit는 italic, textsf는 기본 텍스트 서체로 옮긴다.
원본 083 행렬의 누락 셀은 빈 칸으로 채운다. 084는 단일 토큰 이름,
지원 기호 명령, 빈 이름과 limits를 처리한다. 빈 이름의 첨자는 거부한다.

## 이미 결정된 미지원

| 예제 | 남아 있는 이유 |
| --- | --- |
| 088 | 지원 대상 제외. 내용을 숨기는 phantom. Lap·smash의 일반 배치 정규화와 구별한다. 비교 HTML에 제외 사유를 표시한다. |
| 093, 095 | raisebox 수직 이동과 reflectbox/mathreflectbox 반사 조판은 미지원 유지. |
| 098 | 지원 대상 제외. 예제 전체가 실제 사각형을 그리는 rule이며 비교 HTML에 제외 사유를 표시한다. 096은 사용자 승인으로 rule만 있는 마지막 행을 예제에서 삭제했다. |
| 121, 127 | 사용자 방침에 따라 verb·verb*는 미지원으로 결정하여 두 예제를 지원 대상에서 제외한다. 121의 texttt·텍스트 공백 행은 지원하지만 verb 행을 text로 바꾸거나 지우지 않는다. 비교 HTML에 제외 사유를 표시한다. |
| 123 | 사용자 방침에 따라 text 안의 `$...$` 수식과 텍스트 서체 범위를 오가는 처리는 미지원으로 결정하여 지원 대상에서 제외한다. 내부 수식을 일반 텍스트로 바꾸거나 지우지 않는다. 비교 HTML에 제외 사유를 표시한다. |
| 126 | 지원 대상 제외. 의도적인 알 수 없는 명령 오류 시험. 오류를 유지하며 비교 HTML에 제외 사유를 표시한다. |

060번 이후의 로고 항은 사용자 승인에 따라 원문을 남기고 제거했다.
067은 그룹 또는 명시적 limits가 없는 mathop을 일반 기호로 처리한다.
071은 mathscr 내부의 중첩 수식을 읽으며 영문에는 기존 스크립트 글자를 적용하고
그 밖의 글자·기호는 기본 표기를 유지한다. 072는 matrix*/pmatrix*의
l/c/r 열 정렬 옵션을 읽고 무시하여 기존 matrix/pmatrix로 정규화한다.

## 판단이 필요한 항목

현재 판단이 필요한 항목은 없다.

구문을 읽을 수 있는지, HML 코드를 만들 수 있는지, 한글에서 표시되는지,
원본과 시각적으로 대응하는지는 각각 구별한다. 재추출 코드 일치만으로
시각적 동등성을 선언하지 않는다.

094의 세 반응 화살표는 사용자 결정에 따라 모두 native rel EXARROW로 옮긴다. 089는 각도 기호만, 097·101은 내부 내용을 일반 배치로
처리한다. 093·095의 미지원 및 phantom·rule의 별도 미지원은 유지한다.

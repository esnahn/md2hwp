# 캡션과 출처의 인라인 요소

그림·표 캡션과 코드·그림·표의 모든 출처/주석 문단에서 헤딩·그림·표 번호 상호참조를 사용할 수 있습니다. `[표시문](#대상-ID)`는 대상 종류에 맞는 네이티브 상호참조로 바뀝니다. 표 번호 참조에는 대상 표의 캡션과 자동번호가 필요합니다.

| 위치 | 번호 상호참조 | 각주 |
| --- | --- | --- |
| 그림의 네이티브 캡션과 출처 | 지원 | 금지 |
| 표의 네이티브 캡션 | 지원 | 금지 |
| 코드 박스의 네이티브 캡션에 있는 출처 | 지원 | 금지 |
| 표 마지막 병합 셀의 출처 | 지원 | 현재 미지원 |
| 본문·목록·표 본문 셀 | 지원 | 지원 |

```markdown
![그림 설명과 [절 참조](#section-id)](image.png){#figure-id}

출처: [그림 참조](#figure-id).

참고: 두 번째 문단의 **[절 참조](#section-id)**.
```

캡션과 출처도 `ref.figure.number`·`ref.heading1.number`~`ref.heading6.number`·`ref.table.number` 템플릿을 사용합니다. 참조 표현의 첫 글자 서식과 강조를 유지하며, 출처가 여러 문단일 때 모든 문단을 처리합니다. 그림 대체 텍스트는 메타데이터로 검증하며 별도로 출력하지 않습니다. 그림 캡션에 각주를 넣는 문법은 지원하지 않습니다.

## 한글 2020에서 확인한 동작

한글 2020 HWP 11.0.0.9136에서 그림·표·코드 박스의 네이티브 `CAPTION` 문단에 `InsertCrossReference`를 실행하면 성공합니다. 세 위치 모두 저장·재열기 후 필드, 대상과 표시 번호가 유지되었습니다.

같은 세 위치의 `InsertFootnote`는 모두 실패했습니다. 같은 세션에서 본문에 각주를 삽입하는 대조 시험은 성공했습니다. 따라서 이 버전의 네이티브 캡션 삽입 제약에 따라 각주를 금지합니다. 이 결과가 다른 한글 버전이나 강제로 만든 HWPML 구조의 동작까지 확인한 것은 아닙니다. 제목 슬롯을 통해 캡션으로 복사되는 각주도 오류로 처리합니다.

표 출처는 캡션이 아니라 마지막 병합 셀입니다. 그 영역의 각주 제한은 현재 출처/주석 IR 처리 범위에 따른 것으로, 위 캡션 시험 결과와 구분합니다.

## 현재 데이터에서 확인된 병목

대규모 원본 실행에서 기존 XML 계측 경로의 전체 export는 **379회 / 231.757초**, 선택 영역 export는 **473회 / 63.979초**입니다. 합계 **295.735초**, 백엔드 측정 시간의 **67.0%**입니다. XML 파싱 시간은 별도로 기록했습니다.

## 다음 작업의 비교 기준

1. XML export를 생성에 필요한 조회와 검증 전용 호출로 구분합니다. AuriMinimalBoxPrototype·AuriMinimalCaptionPrototype의 조회는 복제 대상 탐색과 전후 검증이 섞여 있어 호출 위치만 보고 전부 제거할 수 없습니다.
2. TemplateSource.Insert, CurrentParagraphStyle.ReadBlock, RangeRoots, ReadParagraphs, VerifyLists/VerifyText의 반복 호출을 검토합니다. 동일 XML을 여러 검사가 공유할 수 있는지 확인합니다.
3. 전체 HWPML import와 네이티브 HWP 블록 삽입은 별도 비용으로 다룹니다. 실제 생성에 필요한 import를 검증 호출처럼 일괄 제거하지 않습니다.
4. 최종 저장·재열기 검증은 실제 한글 자동번호 변화를 잡고 있습니다. 이번 대규모 실패를 무시한 채 성공 경로 시간으로 비교하지 않습니다.
5. 향후 변경은 같은 원고·템플릿으로 성공/실패 상태, export/import/저장/열기 횟수와 단계별 시간을 비교합니다. 이번 측정 자체는 최적화를 적용하지 않았습니다.

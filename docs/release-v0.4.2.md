# md2hwp v0.4.2

IR 버전과 Markdown 원고 계약은 **0.4** 그대로입니다.

## 변경 사항

- md2hwp를 AGPL-3.0-only로 제공하고, 실행 파일 도움말에 라이선스와 고지 파일을 안내합니다.
- 배포 ZIP에 `LICENSE`, `THIRD-PARTY-NOTICES.txt`, `licenses/`를 포함합니다. Rust 의존성·표준 라이브러리, Unicode 데이터 및 .NET 실행 파일 호스트의 원본 고지를 보존합니다.
- 빌드는 잠금 의존성과 제3자 고지가 일치하는지 확인합니다. 의존성이 바뀌면 고지를 갱신하고 새 조건을 검토해야 합니다.
- Pandoc 다운로드에 Windows 인증서 저장소를 계속 사용하며, 사용하지 않는 기본 인증서 번들 의존성을 제거했습니다.
- Pandoc은 `setup-pandoc`으로 공식 배포본을 별도 다운로드합니다. 실행용 ZIP에는 Pandoc, 한글, 보안 모듈, 서체 또는 전체 .NET 런타임을 넣지 않습니다.

## 실행과 소스

`md2hwp-v0.4.2-windows-x64.zip`에는 실행 파일 세 개, 기본 템플릿, README,
원고 작성 문서 두 개와 라이선스·제3자 고지가 들어 있습니다.
필요한 환경은 [사용법](usage.md)을 참고하십시오.

실행 파일과 대응하는 소스는 동일한 `v0.4.2` 태그의 GitHub 자동 소스 다운로드로
제공합니다. 정확한 의존성 소스 다운로드 링크와 도구 체인 출처는
`THIRD-PARTY-NOTICES.txt`와 `licenses/README.md`에 기록되어 있습니다.
제3자 자료의 권리는 각 원저작자에게 있으며 프로젝트 라이선스가 그 권리를 변경하지 않습니다.

## 검증

Rust 전체 테스트와 Clippy(`-D warnings`), 저장소 로컬 SDK를 사용한 백엔드 계약 테스트,
Release 빌드·패키지 내용·실행 파일 도움말과 버전을 확인했습니다.
이번 변경은 라이선스·의존성·배포 문서 변경이며, 새 한글 COM 실행이나 시각 검증은 수행하지 않았습니다.

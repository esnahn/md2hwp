# 개체의 출처 및 하단 설명 — IR 0.4

그림·박스·표 바로 뒤의 별도 문단을 개체의 하단 설명으로 연결합니다.
이 규칙은 md2hwp 자체 문법이며 CommonMark나 Pandoc 확장이 아닙니다.

## 원고 문법

```markdown
![그림 제목](image.png)

주.1: 조사 대상 기준입니다.

단위: 명

Source.: 자료 제공 기관.

이 문단은 일반 본문입니다.
```

- 문단 첫머리에 지원 접두어가 있어야 합니다. 콜론 앞 공백은 금지하며,
  콜론 뒤에는 공백과 비어 있지 않은 내용이 필요합니다.
- 지원 문단들을 연속해서 연결하며, 일반 문단이나 다른 블록을 만나면 종료합니다.
  접두어 없는 앞 문단을 뒤의 출처를 근거로 소급하여 흡수하지 않습니다.
- 문단 사이에는 빈 줄을 넣습니다. 빈 줄 없이 이어 쓴 줄은 한 문단이며
  여러 하단 문단으로 분리하지 않습니다.
- 영문 대소문자는 구분하지 않습니다. 실제 표기·마침표·번호·순서는 그대로 보존합니다.
- 번호가 없으면 `note:`와 `note.:`를 허용합니다. `주`·`주석`·`note`에만
  ASCII 숫자 접미사를 허용하며 `주1:`, `주.3:`, `note.1:`처럼 적습니다.
  `note1.:`, `주..1:`, `source1:`은 인식하지 않습니다. 번호는 자동 생성·정렬하지 않습니다.
- `출처 : 내용`, 알 수 없는 접두어, `※`는 일반 본문으로 남습니다.
  연결 위치에서 지원 접두어 뒤에 내용이나 구분 공백이 없으면 오류입니다.
- 표 아래 캡션이 있으면 그 캡션 다음에 하단 설명을 둡니다.
- 굵게·기울임·링크 표기·강제 줄바꿈을 보존합니다. 링크는 일반 텍스트로 출력하며
  각주와 번호 상호참조는 이 영역에서 지원하지 않습니다.

## 지원 접두어

한글: 출처, 주, 주석, 참고, 자료, 설명, 비고, 단위, 기준, 해설, 약어, 참조,
주의, 작성, 제공, 재구성, 번역.

영문: source, src, note, annotation, annot, reference, ref, data, description, desc,
remark, remarks, unit, basis, commentary, cmt, abbreviation, abbr, credit, translation, trans.

모든 접두어는 선택적 마침표를 허용합니다. 숫자를 붙일 때는 마침표가 숫자 앞에 옵니다.

## IR

기존 단일 인라인 배열 대신 순서가 있는 문단 배열을 사용합니다.
`prefix`에는 콜론을 제외한 원고 표기를 저장합니다.

```json
"source": [
  {"prefix": "주.1", "inlines": [{"type": "text", "value": "조사 기준"}]},
  {"prefix": "Source.", "inlines": [{"type": "text", "value": "제공 기관"}]}
]
```

출처가 없으면 기존 필드 규칙에 따라 `null` 또는 생략합니다. 빈 배열은 오류입니다.
문단·접두어·인라인 내용은 기존 누적 자원 제한에 포함됩니다.
IR 0.3은 거부하므로 Markdown에서 다시 생성하십시오.

## 템플릿

각 개체의 기존 출처 샘플 문단을 다음처럼 고칩니다.

```text
{{md2hwp:slot:code.source.prefix}}: {{md2hwp:slot:code.source}}
{{md2hwp:slot:figure.source.prefix}}: {{md2hwp:slot:figure.source}}
{{md2hwp:slot:table.source.prefix}}: {{md2hwp:slot:table.source}}
```

각 줄은 해당 개체의 별도 샘플 문단입니다. 기존과 같이 박스·그림은 실제 네이티브
캡션 안에, 표는 마지막 병합 셀 안에 둡니다. 샘플은 하나만 두고 원고 문단 수만큼
복제합니다. 그림 제목 문단은 앞에 보존하며, 하단 문단이 없으면 해당 영역을 생략합니다.
문단 서식은 샘플에서, 접두어·내용의 문자 서식은 각 슬롯의 첫 글자에서 가져옵니다.
내용의 강조는 그 위에 적용합니다. 내어쓰기는 샘플 값을 그대로 복제하며 접두어 길이에
맞춰 자동 재계산하지 않습니다.

`ir-version`도 0.4로 바꾸어야 합니다. `init-template`은 이 구조의 새 템플릿을 만듭니다.
빌드는 Debug/Release 템플릿을 `templates/template.hwp`로 매번 강제 교체합니다.
기본 템플릿은 추적 파일에서 편집하고, 별도 사용자 템플릿은 `target/` 밖에 두십시오.

검증 예제: [여러 하단 문단 원고](../examples/all-features-twice/object-sources.md).

# md2hwp v0.3.0

Markdown 원고를 HWP 문서로 변환합니다.
AURI 보고서 양식의 서식과 문서 구조를 구현·출력하는 것을 기준으로 합니다.

이번 버전에서는 문서 정보, 각주, 표와 번호 상호참조를 지원합니다.

- 원고에 제목·저자·발행일 등을 적어 표지나 머리말에 넣을 수 있습니다. 날짜 표시 형식은 템플릿에서 지정합니다.
- 본문·제목·목록·표 셀에 각주를 넣을 수 있습니다. 여러 문단의 각주와 굵게·기울임도 지원합니다.
- 표의 제목·출처·열 정렬을 지정할 수 있으며, 내용에 맞춰 열 너비를 배분합니다.
- 그림과 장·절 제목에 번호 참조를 넣을 수 있습니다. 참조 위치의 굵게·기울임을 유지합니다.
- 장 시작 번호를 지정할 수 있고, 그림 번호는 장마다 1부터 시작합니다.
- 박스 제목을 본문과 따로 꾸밀 수 있습니다. 목록 항목의 이어지는 문단도 본문 시작 위치에 맞춥니다.

기존의 제목 블록·절 목록 반복, PNG 그림과 실제 한글 캡션을 계속 지원합니다.
생성 문서를 저장·재열기하여 구조와 서식을 검증한 뒤 결과 파일을 교체합니다.
IR 버전은 **0.3**입니다.

## 실행

`md2hwp-v0.3.0-windows-x64.zip`을 풀고 `md2hwp.exe`, `md2hwp-backend.exe`, `template.hwp`를 같은 폴더에 두십시오.

```powershell
.\md2hwp.exe setup-pandoc
.\md2hwp.exe 원고.md
```

원고 옆에 `원고.ir.json`과 `원고.output.hwp`가 생성됩니다.
다른 템플릿은 `--template 내템플릿.hwp`로 지정할 수 있습니다.

동봉 템플릿을 사용할 때는 원고 맨 앞에 문서 제목을 적으십시오. 문서 제목과 첫 장 제목은 별개입니다.

```yaml
---
title: 보고서 제목
---
```

## 필요한 환경

Windows x64, 한글, .NET 10 x64 런타임, 설치·등록된 한글 보안 모듈이 필요합니다.
기준 검증 환경은 한글 2020입니다. 변환 전에 실행 중인 한글 문서를 닫아 주십시오.

보안 모듈은 [한컴 공식 한글 오토메이션 페이지](https://developer.hancom.com/hwpautomation)에서 **보안모듈(Automation).zip**을 내려받아 동봉된 안내에 따라 현재 사용자 계정에 등록하십시오.
등록 이름은 `FilePathCheckerModuleExample`이며, `REG_SZ` 값에 DLL의 절대 경로를 지정합니다. 프로그램은 보안 모듈을 자동으로 설치하거나 등록하지 않습니다.

> [!TIP]
> 저장소의 [설치 스크립트](https://github.com/esnahn/md2hwp/blob/v0.3.0/dependencies/install-hancom-security-module.ps1)를 사용할 수도 있습니다. GitHub의 **Source code (zip)**을 풀고, 한글을 모두 닫은 뒤 저장소 루트에서 실행하십시오.
>
> ```powershell
> powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\dependencies\install-hancom-security-module.ps1
> ```
>
> 실행용 배포 ZIP에는 이 스크립트가 포함되지 않습니다.

## 이전 버전 사용자

0.2에서 만든 IR은 Markdown 원고에서 다시 생성해야 합니다.
기존 템플릿도 새 선언을 반영하거나 `md2hwp init-template 새템플릿.hwp`로 별도 파일을 만들어 사용하십시오.
사용자 템플릿은 자동으로 갱신하지 않으므로, 새 배포 파일을 풀기 전에 기존 템플릿을 백업하십시오.

장·절 번호 참조를 사용하려면 템플릿의 대상 제목에 실제 한글 개요 번호가 설정되어 있어야 합니다. 동봉 템플릿은 2~4단계 제목에 개요 번호가 설정되어 있습니다.

HWPX·RST 직접 입력과 표·쪽 번호 상호참조는 지원하지 않습니다. 일반 링크는 연결 기능 없이 표시문으로 출력합니다.
변환 후 긴 제목·표·박스의 잘림이나 겹침과 각주 표시 번호를 확인하십시오. 동봉 템플릿의 앞 빈 페이지는 유지됩니다.

자세한 내용은 [설치·실행 안내](usage.md), [원고 작성](manuscript.md), [템플릿 편집](templates.md)을 참고하십시오.

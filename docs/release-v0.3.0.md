# md2hwp v0.3.0 릴리스 노트

프로그램·백엔드 버전은 **0.3.0**, IR 버전은 **0.3**입니다.
Windows x64용 릴리스입니다. 배포 파일은 [GitHub Release](https://github.com/esnahn/md2hwp/releases/tag/v0.3.0)에서 제공합니다.

## 주요 변경 사항

- YAML 문서 정보와 사용자 문자열 치환을 지원합니다. 날짜를 인식하면 `date-meta`를 생성하고 템플릿에서 표시 형식을 지정할 수 있습니다.
- 참조형 각주와 여러 문단의 각주를 지원합니다. 실제 한글 각주 샘플에서 서식·탭·자동번호를 가져오며, `footnote.next`로 후속 문단을 따로 꾸밉니다.
- 헤딩 1~6단계와 그림 번호를 한글의 실제 상호참조 필드로 출력합니다. 참조는 원고 위치의 글자 서식과 굵게·기울임을 유지합니다.
- 파이프 표의 캡션·출처·정렬·서식·각주·번호 참조와 내용 기반 열 너비를 지원합니다. `Table:`, `table:`, `:`, `표:` 캡션을 표 앞뒤에서 연결합니다.
- 3행·2열 표 원형의 좌우 셀에서 외곽·내부 세로 테두리를 가져오고, 병합 출처행의 공유 경계를 보존합니다. 머리행과 첫 본문 행이 다른 쪽·단에서 시작하면 생성 표의 배치를 보정합니다.
- 박스 제목 슬롯과 줄별 본문 서식을 지원합니다. 공백·탭·본문 빈 줄을 보존하며, 한글이 다시 계산하는 박스 표 높이와 실제 구조 손실을 구분합니다.
- 목록 기호의 샘플 서식을 유지하며, 같은 항목의 둘째 이후 문단은 기호 없이 본문 시작 위치에 맞춥니다.
- 헤딩 블록·하위 제목 반복·장 시작 번호와 장별 그림 번호 재시작을 지원합니다.
- 문단 스타일 확인에 선택 블록 내보내기를 사용해 반복되는 전체 문서 읽기를 줄였습니다. 측정 조건과 결과는 [성능 기록](render-performance.md)을 참고하십시오.

## 설치와 실행

`md2hwp.exe`, `md2hwp-backend.exe`, `template.hwp`를 같은 폴더에 둡니다.
한글, .NET 10 x64 런타임과 현재 사용자 계정의 한글 보안 모듈 등록이 필요합니다.
Pandoc은 다음 명령으로 별도 준비합니다.

```powershell
.\md2hwp.exe setup-pandoc
.\md2hwp.exe 원고.md
```

기본 출력은 원고 옆의 `원고.ir.json`과 `원고.output.hwp`입니다.
HWP는 저장·재열기 및 구조 검증에 성공한 뒤 교체합니다. 실패하면 이전 HWP를 보존합니다.
설치·실행 옵션은 [사용 안내](usage.md), 원고 문법은 [원고 작성](manuscript.md)에 있습니다.

## 이전 버전에서 전환

0.2 IR은 원고에서 다시 생성해야 합니다. 템플릿 IR 버전도 0.3과 일치해야 합니다.
같은 IR 0.3을 사용하는 기존 사용자 템플릿도 새 각주·참조·목록·표 선언을 직접 반영하거나
`init-template`으로 별도 파일을 생성해야 합니다. 이전 3행·1열 표 원형은 지원하지 않습니다.
기존 사용자 `target/release/template.hwp`는 빌드가 덮어쓰지 않습니다.

동봉 기본 템플릿에는 YAML `title`이 필요하며 heading2~heading4에 개요 번호가 설정되어 있습니다.
다른 수준을 번호 참조하려면 대상 문단의 실제 Outline 설정과 비어 있지 않은 번호 표시 형식을 확인하십시오.
`init-template`이 만드는 새 템플릿의 헤딩은 일반 문단이므로 필요한 개요 번호를 직접 설정합니다.
템플릿 편집은 [템플릿 안내](templates.md)를 따릅니다.

## 지원 범위와 배치 확인

HWPX·RST 직접 입력, 인라인 코드·인용 블록·HTML, 중첩 각주와 비문단 각주 본문,
병합 원고 표·여러 머리행·셀 안 여러 문단, 표·쪽 번호 상호참조는 지원하지 않습니다.
미지원 요소는 명시적으로 오류를 냅니다. 일반 링크는 표시문과 글자 서식으로 출력합니다.

동봉 템플릿의 앞 빈 페이지는 유지합니다.
고정 크기 제목 상자와 긴 표·박스의 잘림·겹침, 실제 각주 표시 번호는 생성 결과에서 확인해야 합니다.
저장·재열기 구조 검사만으로 모든 원고의 시각적 배치 안전성을 보장하지 않습니다.

## 검증 기록

이번 릴리스 준비에서 다음 검사를 다시 수행했습니다.

- `cargo test --workspace`: 88개 테스트 통과.
- `cargo clippy --workspace --all-targets -- -D warnings`: 통과.
- 저장소 고정 .NET SDK의 백엔드 계약 테스트: 통과.
- `tools/development/build.ps1 -Configuration Release`: 통과.
- 배포 실행 파일 두 개의 버전 0.3.0, ZIP 항목과 SHA-256, 원본·검증용 템플릿의 해시 확인.
  빌드 시작 시 `target/release/template.hwp`가 없어 기본 템플릿을 새로 복사했습니다.

최신 실행 파일과 편집 템플릿의 별도 사본으로 통합 원고를 실제 변환했습니다.
저장·재열기 구조 검증이 통과했고, 재생성한 IR은 추적된 예상 IR과 SHA-256이 일치합니다.
17페이지 전체 모음과 대표 3·4·5·6·7·11·12·13·14·15페이지를 확인했습니다.
각주 표시 번호 1~14, 상호참조 줄 배치·강조, 목록 기호·이어지는 문단,
박스 제목·본문·출처, 그림 캡션, 표 테두리·병합 출처행을 확인했습니다.
이 표본에서 잘림·겹침은 발견하지 못했으며 첫 빈 페이지는 유지됩니다.
검증 자료는 ignored `artifacts/release-v0.3.0-final/`에 보관합니다.
이번 확인은 긴 표나 모든 원고의 배치 안전성을 보장하지 않습니다.
이전 대규모 문서의 112쪽·성능 비교 기록은 해당 측정 당시 조건에 한정됩니다.

## 배포 파일

GitHub Release에 다음 파일을 제공합니다. 저장소에서 만든 배포 파일은 `target/dist/`에도 보관합니다.

- `md2hwp-v0.3.0-windows-x64.zip`: 실행 파일 두 개와 추적 기본 `template.hwp`.
- `md2hwp-v0.3.0-source.zip`: v0.3.0 태그의 추적 소스·문서·예제.
- `md2hwp-v0.3.0-release-notes.md`: 릴리스 본문.
- `md2hwp-v0.3.0-SHA256SUMS.txt`: 배포 파일의 SHA-256.
- `v0.3.0-build-manifest.json`: 소스 커밋, 빌드·검증 결과와 파일 해시.

실행용 ZIP에는 SDK, Pandoc, 한글 보안 모듈, 개발용 lock 파일과 사용자 바로 가기를 포함하지 않습니다.

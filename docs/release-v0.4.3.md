# md2hwp v0.4.3

IR 버전과 Markdown 원고 계약은 **0.4** 그대로입니다.

## 변경 사항

- `md2hwp validate 원고.md`로 변환 전에 엄격한 원고 작성 규칙과 AST/IR 계약을 검사합니다. 개체에 연결되지 않은 출처·주·표 캡션, 접두어, 각주, 코드 울타리와 표 칸 수 등을 확인합니다. `--require-meta`를 반복해 필수 YAML 키를 지정할 수 있습니다. Pandoc은 필요하며 한글 없이 실행하고 파일을 생성하지 않습니다.
- `md2hwp validate-template [template.hwp]`로 템플릿의 IR 버전·선언·슬롯·원형 구조와 메타데이터 태그를 검사합니다. 경로 생략 시 EXE 옆의 템플릿을 사용합니다. 한글과 보안 모듈이 필요하며 원본을 저장하지 않습니다. 백엔드 직접 실행도 지원합니다.
- 템플릿 검사 결과에는 필요한 YAML 키와 인식 가능한 날짜의 필요 여부가 표시됩니다.
- 원고 검사 성공 메시지를 간결하게 정리했습니다. 일반 변환의 문단 처리 방식은 유지합니다.
- 기본 템플릿의 `except.once` 시작·끝 문단은 바탕글 스타일과 실제 글자 모양이 일치하도록 수정했습니다. 이 템플릿 수정은 v0.4.1·v0.4.2 재배포에도 반영됐습니다.

## 실행과 소스

```powershell
.\md2hwp.exe validate 원고.md --require-meta title
.\md2hwp.exe validate-template
.\md2hwp.exe validate-template 내템플릿.hwp
```

실행용 ZIP에는 실행 파일 세 개, 기본 템플릿, README, 원고 작성 문서 두 개와
프로젝트 라이선스·제3자 고지가 들어 있습니다. 설치와 옵션은 [사용법](usage.md)을 참고하십시오.

실행 파일과 대응하는 소스는 동일한 `v0.4.3` 태그의 GitHub 자동 소스 다운로드로 제공합니다.
의존성 소스와 도구 체인 출처는 `THIRD-PARTY-NOTICES.txt`와 `licenses/README.md`에 기록돼 있습니다.
제3자 자료는 각 원저작자의 조건을 따릅니다.

## 검증

Rust 전체 테스트·Clippy, Debug/Release 백엔드 계약 테스트, Release 빌드,
ZIP 내용과 실행 파일 세 개의 버전·도움말을 확인했습니다. 원고 검사 성공·실패와
템플릿의 실제 한글 검사를 확인했습니다. 이 릴리스 준비에서 페이지 이미지 시각 검증은 하지 않았습니다.

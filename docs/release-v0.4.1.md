# md2hwp v0.4.1

IR 버전과 Markdown 원고 계약은 **0.4** 그대로입니다.

## 변경 사항

- 템플릿의 `begin:except.once` / `end:except.once` 범위는 해당 수준의 두 번째 이후 헤딩에만 적용합니다. 기존 `once` 범위는 첫 헤딩에만 적용합니다.
- 두 태그는 같은 문단 또는 같은 컨테이너의 여러 문단에 둘 수 있습니다. 문단 중간의 태그도 지원하며, 범위 안의 문자와 네이티브 제어 및 문단 경계를 함께 처리합니다.
- 두 태그가 다른 문단에 있으면 끝 태그 문단의 쪽 나눔과 단 나눔을 범위에 포함합니다. 같은 문단의 범위는 문단 나눔 속성을 변경하지 않습니다.
- 기본 템플릿은 Heading1 앞의 쪽 나눔을 `except.once`로 감싸 첫 장 앞 빈 쪽을 없애고, 두 번째 장부터 강제 쪽 나눔을 유지합니다. 구역 설정과 바탕쪽은 기존 위치에 유지합니다.

## 기존 템플릿

현재 IR 0.4의 기존 템플릿에 새 태그를 추가할 필요는 없습니다. `except.once`는 선택 기능이며,
기존 `once`와 범위 밖 쪽 나눔은 유지합니다. 기존 템플릿의 첫 장 앞 빈 쪽은 자동 제거하지 않습니다.
새 태그를 채택한 템플릿은 v0.4.1 백엔드를 사용하십시오.

## 실행과 패키지

`md2hwp-v0.4.1-windows-x64.zip`에는 `md2hwp.exe`, `md2hwp-backend.exe`, `hwp2pdf.exe`,
`template.hwp`, `README.md`, 원고 작성용 `AGENTS.md`와 `README-MANUSCRIPT.md`가 들어 있습니다.
필요한 환경과 실행 방식은 [사용법](usage.md)을, 태그 문법은 [템플릿 안내](templates.md)를 참고하십시오.

## 검증

한글 2020에서 변경 전 기본 템플릿으로 두 장 문서와 통합 기능 IR 예제를 실제 생성하고
저장 및 재열기 검증을 통과했습니다. 기존 두 장 결과는 변경 전과 같은 5쪽이며,
다섯 쪽의 한글 페이지 이미지의 픽셀도 일치했습니다. 기존 템플릿은 수정하지 않았습니다.

새 기본 템플릿의 두 장 결과는 빈 쪽 없이 4쪽입니다. 문단 중간에 시작/끝 태그와 문자를
넣은 별도 테스트에서도 첫 장의 범위 안 문자와 끝 문단의 쪽 나눔을 제거하고,
두 번째 장에는 유지하는 것을 실제 페이지로 확인했습니다.
이 확인은 해당 예제의 배치 검증이며 모든 사용자 템플릿의 배치를 보장하지 않습니다.

Rust 전체 테스트와 Clippy(`-D warnings`), 저장소 로컬 SDK를 사용한 Release backend
계약 테스트를 통과했습니다. 이 계약 테스트 자체가 실제 한글 표시를 검증하는 것은 아닙니다.

# Local reference inputs

This directory holds upstream manuals, report templates, fonts, and related
research inputs. Its current contents are retained locally but ignored by Git
because their provenance, license, and redistribution terms have not been
recorded as repository policy.

Reference material is not an implicit production input. Tests and packaging
must use an explicitly supplied path or a provenance-cleared fixture. Before
versioning any file here, record its source URL or delivery origin, document
version/date, SHA-256, license, and redistribution decision.

# 짧은 전체 기능 검증 원고

[`all-features.md`](all-features.md)는 같은 내용을 두 번 반복하지 않고 현재 지원 기능을
한 원고에 모은 예제입니다. 예상 IR은 [`all-features.ir.json`](all-features.ir.json)입니다.
함께 둔 그림 파일을 포함해 이 폴더만 복사해서 변환할 수 있습니다.

```powershell
.\target\release\md2hwp.exe .\examples\all-features\all-features.md
```

원고 옆에 `all-features.ir.json`과 `all-features.output.hwp`가 생깁니다.
IR만 다시 만들려면 `md2ir` 명령과 `--force`를 사용합니다.

```powershell
.\target\release\md2hwp.exe md2ir .\examples\all-features\all-features.md --force
```

## 보고서 내용과 시험 자료

주제와 용어는 로컬 `reference/auri/01 auri 기본연구보고서 작성양식.hwp`에 수록된
「유산영향평가 제도 도입에 따른 세계유산 공간관리 정책방안 연구 — 세계유산지구 밖
주변환경을 중심으로」의 논의를 요약·재구성했습니다. 연구 배경·관리구역·조사 자료·협의
절차를 짧게 구성하며, 원본의 전체 내용이나 현재 법령·통계를 재현하는 예제가 아닙니다.
날짜는 참고 보고서의 발행일인 2024-12-31입니다. 저자·보고서 번호·표 수치는 검증용입니다.

PNG와 JPG/JPEG는 기존 검증 자료입니다. 보고서의 실제 도면·조사 사진으로 표시하지 않습니다.
일반 EMF·EMF+ Dual·EMF+ Only는 [`generate.ps1`](../emf/generate.ps1)로 만든
재현 자료를 바이트 그대로 복사했습니다. 이미지 자체의 전문 검증 기록은
[EMF](../../docs/emf-figures.md)와 [PDF 품질](../../docs/hwp2pdf-quality-matrix.md)에 있습니다.

## 포함한 기능

| 범위 | 확인할 내용 |
| --- | --- |
| 문서 정보 | title·subtitle·author 목록·한국어 date·파생 date-meta·publisher·사용자 키·비재귀 값·장 시작 번호 3 |
| 제목 | heading1~6, ID 없는 제목, 장마다 여러 절과 한 절의 여러 하위 제목, 계산된 번호와 each.child |
| 본문 | Unicode, 일반/강제 줄바꿈, 굵게·기울임·중첩 강조, 링크 표시문·자동 링크 입력·URL·이메일 |
| 목록 | 글머리/번호, 촘촘한/느슨한 목록, 다문단 항목, 시작 번호 3과 괄호 입력, 깊이 6, 양방향 혼합 중첩 |
| 글상자 | 제목+본문/제목만/본문만, 제목 뒤 빈 줄 제거, 공백·탭·본문 빈 줄·문법 문자 보존, 다중 설명 문단과 설명 생략 |
| 그림 | PNG/JPG/progressive JPEG/일반 EMF/EMF+ Dual/EMF+ Only, 서식 있는 캡션, 다중 설명 문단과 설명 생략, 장 간 번호 재시작 |
| 표 | ID와 번호 참조, 위/아래 캡션, 캡션·출처 각각 생략, 머리행 전용/단일 열, 4종 정렬, 빈 셀·강조·링크·각주·참조 |
| 하단 설명 | 한국어/영문 접두어, 마침표·번호, 순서·문단 유지, 강조·링크·번호 참조 |
| 각주 | 본문·heading6·목록·표 셀·강조·링크 표시문, 여러 문단·서식·강제 줄바꿈·동일 정의 재사용 |
| 번호 참조 | 제목 6수준·그림·표, 앞뒤/장 간 대상, 한글 ID·URI 이스케이프·빈 표시문·참조형 링크, 본문·목록·캡션·설명·각주·셀 |

메타데이터의 각 항목과 날짜 fmt, 제목/each.child 번호, 제어문자 once, 각주 후속 문단의
서식은 해당 선언을 둔 템플릿에서 시험합니다. 템플릿에 없는 출력 역할을 Markdown만으로
추가하지는 않습니다. 긴 표의 반복 머리행·쪽 나눔과 큰 원고의 성능은
[`large-5x.md`](../korean-lorem/large-5x.md)로 별도 검증합니다.

탭 입력도 포함하지만 CommonMark를 읽는 Pandoc은 코드 블록의 탭을 공백으로 확장합니다.
백엔드가 받는 원문은 IR에 기록된 줄입니다. 직접 IR에 들어온 탭 보존은 기존 계약 테스트로 확인합니다.

컴파일·계약 테스트용 자료와 기능별 회귀 예제는 [`examples/README.md`](../README.md)에
정리합니다. 생성 HWP/PDF는 Git에 포함하지 않습니다.

## 현재 원고 검증

2026-10-10, v0.4.0 Release와 추적 기본 템플릿으로 실제 HWP 생성·저장·재열기 검증을
통과했습니다. 실행 중 원고·이미지·원본 템플릿은 변경되지 않았고, 생성 IR이 예상 IR과
일치했습니다. PDF로 확인한 14쪽에는 PNG/JPEG/EMF, 다중 하단 설명, 각주, 표와 장 간
번호 참조가 표시됩니다. 본문 강조의 별표 잔존은 수정했으며 코드 블록의 별표는 원문대로
남습니다. 첫 빈 쪽은 기존 템플릿의 쪽 나눔 설정을 따릅니다.

Rust 워크스페이스 테스트와 Release 백엔드 계약 테스트도 통과했습니다.
이 결과는 이 원고·템플릿의 확인 기록이며 다른 제목 길이나 용지·서체의 배치 안전성을
보장하지 않습니다. 원본 대규모 원고·예상 IR·이미지는 수정하지 않았습니다.

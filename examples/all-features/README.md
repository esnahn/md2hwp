# 짧은 전체 기능 검증 원고

[`all-features.md`](all-features.md)는 같은 내용을 두 번 반복하지 않고 현재 지원 기능을
한 원고에 모은 예제입니다. 예상 IR은 [`all-features.ir.json`](all-features.ir.json)입니다.
함께 둔 그림 파일을 포함해 이 폴더만 복사해서 변환할 수 있습니다.

```powershell
.\target\release\md2hwp.exe .\examples\all-features\all-features.md
```

원고 옆에 `all-features.ir.json`과 `all-features.output.hwp`가 생깁니다.
IR만 다시 만들려면 `md2ir` 명령과 `--force`를 사용합니다.

```powershell
.\target\release\md2hwp.exe md2ir .\examples\all-features\all-features.md --force
```

## 보고서 내용과 시험 자료

주제와 용어는 로컬 `reference/auri/01 auri 기본연구보고서 작성양식.hwp`에 수록된
「유산영향평가 제도 도입에 따른 세계유산 공간관리 정책방안 연구 — 세계유산지구 밖
주변환경을 중심으로」의 논의를 요약·재구성했습니다. 연구 배경·관리구역·조사 자료·협의
절차를 짧게 구성하며, 원본의 전체 내용이나 현재 법령·통계를 재현하는 예제가 아닙니다.
날짜는 참고 보고서의 발행일인 2024-12-31입니다. 저자·보고서 번호·표 수치는 검증용입니다.

PNG와 JPG/JPEG는 프로젝트 소유자를 위해 AI로 생성한 항공 시점 동네 이미지와 변환본입니다.
소유자가 2026-10-11에 출처를 확인했습니다. [이미지 출처와 라이선스](../IMAGE-PROVENANCE.md)를
참고하십시오. 보고서의 실제 도면·조사 사진으로 표시하지 않습니다.
일반 EMF·EMF+ Dual·EMF+ Only는 [`generate-emf.ps1`](generate-emf.ps1)로 만든
재현 자료를 바이트 그대로 복사했습니다. SVG 두 개는 이 저장소에서 직접 작성했습니다.
[`vector-features.svg`](vector-features.svg)는 EMF로 들어가는 SVG 기능을 모두 모은 그림이고
(안에 넣은 작은 PNG·JPEG도 직접 만든 색 무늬입니다), [`raster-fallback.svg`](raster-fallback.svg)는
그라데이션·마스크·필터를 써서 PNG로 바뀌는 그림입니다. 원고 옆의 `vector-features.svg.emf`와
`raster-fallback.svg.png`는 변환할 때 만들어지는 파일이며, EMF의 글자 윤곽은 설치된 글꼴(맑은 고딕)에 따라
달라질 수 있습니다. 기능 목록은 [SVG 그림](../../docs/svg-figures.md#지원-기능-목록)에 있습니다.
이미지 자체의 전문 검증 기록은
[EMF](../../docs/emf-figures.md)와 [PDF 품질](../../docs/hwp2pdf-quality-matrix.md)에 있습니다.

## 포함한 기능

| 범위 | 확인할 내용 |
| --- | --- |
| 문서 정보 | title·subtitle·author 목록·한국어 date·파생 date-meta·publisher·사용자 키·비재귀 값·장 시작 번호 3 |
| 제목 | heading1~6, ID 없는 제목, 장마다 여러 절과 한 절의 여러 하위 제목, 계산된 번호와 each.child |
| 본문 | Unicode, 일반/강제 줄바꿈, 굵게·기울임·중첩 강조, 취소선·위 첨자·아래 첨자와 강조 겹침, 글자 그대로 남는 물결표, 링크 표시문·자동 링크 입력·URL·이메일 |
| 목록 | 글머리/번호, 촘촘한/느슨한 목록, 다문단 항목, 시작 번호 3과 괄호 입력, 깊이 6, 양방향 혼합 중첩 |
| 글상자 | 제목+본문/제목만/본문만, 제목 뒤 빈 줄 제거, 공백·탭·본문 빈 줄·문법 문자 보존, 다중 설명 문단과 설명 생략 |
| 그림 | PNG/JPG/progressive JPEG/일반 EMF/EMF+ Dual/EMF+ Only/SVG(EMF로 바뀌는 그림과 PNG로 바뀌는 그림), 서식 있는 캡션, 다중 설명 문단과 설명 생략, 장 간 번호 재시작 |
| 수식 | 본문·목록·각주 안의 글줄 수식, 번호가 붙는 별행 수식 두 개(정렬된 4행 맥스웰 방정식, 슈뢰딩거 방정식) |
| 표 | ID와 번호 참조, 위/아래 캡션, 캡션·출처 각각 생략, 머리행 전용/단일 열, 4종 정렬, 빈 셀·강조·취소선·첨자·링크·각주·참조 |
| 하단 설명 | 한국어/영문 접두어, 마침표·번호, 순서·문단 유지, 강조·링크·번호 참조 |
| 각주 | 본문·heading6·목록·표 셀·강조·링크 표시문, 여러 문단·서식·강제 줄바꿈·동일 정의 재사용, 각주 안의 수식·취소선·첨자 |
| 번호 참조 | 제목 6수준·그림·표, 앞뒤/장 간 대상, 한글 ID·URI 이스케이프·빈 표시문·참조형 링크, 본문·목록·캡션·설명·각주·셀 |
| 주석 | 틀린 문법 예시를 담은 문서 앞 여러 줄 주석, 문장(한 줄·여러 줄)·제목·목록 항목·표 셀·각주 안 주석, 목록 항목·각주 안 블록 주석, 캡션과 표·개체와 하단 설명·하단 설명 사이의 주석 블록, 이어 붙인 두 주석 |

메타데이터의 각 항목과 날짜 fmt, 제목/each.child 번호, 제어문자 once, 각주 후속 문단의
서식은 해당 선언을 둔 템플릿에서 시험합니다. 템플릿에 없는 출력 역할을 Markdown만으로
추가하지는 않습니다. 긴 표의 반복 머리행·쪽 나눔과 큰 원고의 성능은
[`large-5x.md`](../korean-lorem/large-5x.md)로 별도 검증합니다.

탭 입력도 포함하지만 CommonMark를 읽는 Pandoc은 코드 블록의 탭을 공백으로 확장합니다.
백엔드가 받는 원문은 IR에 기록된 줄입니다. 직접 IR에 들어온 탭 보존은 기존 계약 테스트로 확인합니다.

컴파일·계약 테스트용 자료와 기능별 회귀 예제는 [`examples/README.md`](../README.md)에
정리합니다. 생성 HWP/PDF는 Git에 포함하지 않습니다.

## 현재 원고 검증

2026-11-16, 추적 기본 템플릿과 Release 빌드(rhwp 고정 커밋 `1a76570`)로 rhwp·한글 두 백엔드에서 각각
HWP를 만들어 저장·재열기 검증을 통과했습니다. 한글 2020에서 PDF로 내보낸 결과는 두 백엔드 모두 17쪽입니다.

- 취소선, 위·아래 첨자, 글줄 수식, 번호가 붙은 별행 수식 세 개, SVG 그림 두 개가 표시되는 것을 쪽 이미지로 확인했습니다.
- `vector-features.svg`의 EMF는 한글에서 9칸 모두 Windows GDI+로 그린 결과와 같게 보입니다.
- 두 백엔드의 쪽 이미지는 17쪽 중 10쪽이 픽셀까지 같습니다. 나머지 7쪽은 수식이 있는 쪽(수식 크기를
  rhwp는 추정값으로, 한글은 직접 계산해 넣음)과 JPEG·그림이 있는 쪽(한글의 이미지 재압축)입니다.
- 별행 수식 가운데 맥스웰 방정식과 슈뢰딩거 방정식은 원고의 TeX가 한글 수식 스크립트를 거쳐 같은 TeX로
  돌아옵니다. 표준 모형 라그랑지안은 `\text{h.c.}`가 `\mathrm{h.c.}`로 돌아와 TeX가 달라지며, 표시만 확인했습니다.

2026-11-18에 HTML 주석을 넣은 원고도 엄격 검사를 경고 없이 통과했고, 만든 IR이 주석을 넣기 전의
`all-features.ir.json`과 바이트까지 같습니다. 따라서 위 HWP 결과는 그대로이며 주석을 넣은 뒤 한글에서 다시 보지는 않았습니다.

이 결과는 이 원고·템플릿의 확인 기록이며 다른 제목 길이나 용지·서체의 배치 안전성을 보장하지 않습니다.
HWPX 출력과 한글 외 뷰어의 표시는 확인하지 않았습니다.
